# Spending Calculator

A simple Java console application that calculates a user's spending
category based on their monthly income and expense.

## Features

- Accepts monthly income and expense
- Validates positive input
- Categorizes spending as:
  - Safe
  - Moderate
  - Risky
- Provides spending advice
- Uses methods and instance variables

## Technologies

- Java
- OOP fundamentals
